# Backend Validators
This directory contains request body and query parameter validation schemas:
- `authValidator.js` (Phase 2): Validates registration and login payloads.
- `playerValidator.js` (Phase 3): Validates player creation and update payloads.
- `sessionValidator.js` (Phase 4): Validates practice session dates, sports, and attendance records.
- `matchValidator.js` (Phase 5): Validates match parameters and score bounds.
