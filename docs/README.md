**Words used in these docs**

| Word | Meaning |
| --- | --- |
| Academy | One sports club. Its data is private to its own members |
| Head Coach | The person who created the academy. Manages join codes |
| Join code | A code like `K7P2-9QX4-M3T8` that lets a coach or scout join an academy |
| Session | A practice session. It's *open* while attendance is marked and *closed* once final |
| Ready | At least 75% attendance in closed sessions **and** at least 2 matches played |
| Evaluation mode | A switch that shows demo logins and codes to judges |
